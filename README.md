# NovaPulse AI ⚡ - Intelligent Autonomous Wellness Platform

> Built with **Google Antigravity** & iteratively enhanced using **Claude 3.5 Sonnet** and **OpenAI Codex**.

NovaPulse AI bridges deep circadian biology with predictive neural intelligence. It transforms fragmented sleep, mental fatigue, and stress spikes into continuous daily flow states using on-device, zero-knowledge machine learning.

## 🌟 Key Features

- **Multi-Page Web Experience**:
  - `index.html`: Dynamic Hero, Live Bio-Sync Visualizer, Interactive Vitality Score Calculator, Core Feature Showcase, Testimonial Grid, CTA Banner.
  - `about.html`: Circadian Neural Architecture, Edge Inference Breakdown, Interactive Comparison Matrix, 2026 Product Roadmap, Scientific Advisory Board.
  - `pricing.html`: Interactive Monthly / Annual Billing Switcher with 25% discount calculation, 3 Transparent Subscription Tiers, Live Searchable FAQ Accordion.
  - `contact.html`: VIP Early Access Alpha Application with Real-Time Client-Side Validation, Dynamic Toast Notification Manager, and Local Session Submission Inspector.
- **Glassmorphism Design System**: Modern dark & light mode support with CSS custom property design tokens, backdrop filters, and responsive mobile navigation drawer.
- **High Performance & Zero Dependencies**: 100/100 Lighthouse-ready with semantic HTML5, zero heavy third-party framework overhead, and instant load times.
- **Universal Deployment Ready**: Pre-configured for instant zero-configuration deployment to **Vercel** (`vercel.json`), **Netlify** (`netlify.toml`), or **GitHub Pages**.

## 🚀 Quick Start (Local Development)

### Option 1: Direct Browser Preview
Double-click `index.html` or open it directly in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local Static Server (Node.js / Python / PowerShell)
```bash
# Using Python
python -m http.server 3000

# Using Node.js npx
npx serve .

# Open http://localhost:3000 in your browser
```

---

## 🌐 Instant Deployment

### Deploy to Vercel
```bash
npx vercel
```

### Deploy to Netlify
```bash
npx netlify deploy --prod
```

### Deploy to GitHub Pages
1. Push repository to GitHub.
2. Go to **Settings** > **Pages** > Select `main` branch root `/` > **Save**.
